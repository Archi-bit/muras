# MURAS — A living map of Kyrgyzstan

Публичная демонстрация: [archi-bit.github.io/muras](https://archi-bit.github.io/muras/).

Локальный интерактивный MVP: HTML, CSS, Vanilla JavaScript, Leaflet 1.9.4 и localStorage. Backend, сборка, установка npm-пакетов и авторизация для приложения не нужны. Интерфейс на английском.

## Запуск

В папке проекта выполните:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173. Остановка: Ctrl+C. Можно открыть `index.html` напрямую, но для предсказуемого localStorage и буфера обмена рекомендуется HTTP. Карта OpenStreetMap требует интернет; переключатель **Use offline atlas** открывает локальную карту с географическим контуром, фильтрами и метками. При недоступности тайлов резервный режим включается автоматически. Атлас не является навигационной или юридической картой; близкие музейные метки разнесены для выбора.

## Реализовано

- Шесть культурных мест, настоящие локальные фотографии с лицензиями, исторические описания и ссылки на источники.
- Карта, поиск, категории, карточки, связанные истории, события и сообщения.
- Четыре исторических материала и четыре события с опубликованными датами. Статусы событий рассчитываются по дате в Asia/Bishkek; программа на месяц не представлена как ежедневное мероприятие.
- Личные воспоминания с атрибуцией, обязательным согласием, фотографией и аудио; очередь публикаций и явное отделение от исторических фактов.
- Два явно вымышленных сообщения: мусор у Бураны и возможное граффити на исторической поверхности.
- Раздельные статусы сообщения, публикации и волонтёрского предложения; допустимые переходы, демонстрационные роли и история действий.
- Уборка требует проверки сообщения, согласования зоны и надзора в демо. Регистрация открывается отдельным шагом после **Approved for Demo**. Повторная запись из того же браузера блокируется. Завершение требует описания и числа условных участников, а результат остаётся под проверкой.
- Работы на исторических поверхностях нельзя согласовать как обычную волонтёрскую уборку. Для них предусмотрены запрос специалиста и черновик обращения.
- Редактирование, сохранение, копирование и скачивание обращения; пользовательский трекер отправки с явным подтверждением каждого этапа.
- Проверки полей, ссылок, размера и формата файлов, возможных дублей и повторяющегося текста. Эти правила не называются ИИ.
- localStorage, безопасное восстановление после некорректных данных и **Reset Demo Data**.

## Демонстрация за 90 секунд

Перед показом нажмите **Reset Demo Data** и подтвердите сброс. Кнопка **Start the 90-second demo** открывает нужные экраны, но не выполняет согласования вместо пользователя.

1. **0:00–0:15:** Explore Map — покажите карту, выберите Museums, затем All Places.
2. **0:15–0:30:** Burana Tower → Read the history. Покажите сведения и UNESCO, закройте окно.
3. **0:30–0:45:** Take Action → Sample Report: Litter Near Burana Tower. Покажите Demo Scenario, Awaiting Review, Automated Preliminary Checks.
4. **0:45–1:05:** Demo Review Panel → Moderator Demo → Reviewed in Demo → Confirm Demo Change. Затем Site Manager Demo → Volunteer Proposals. Для Community Cleanup последовательно: Preliminary Review → Permission Required → Awaiting Approval → Simulate Permission (два подтверждения зоны и надзора) → Open Registration. Каждый шаг подтверждается кнопкой Confirm Demo Change. View activity → Join Activity. Число участников становится 1.
5. **1:05–1:20:** Закройте окно → Take Action → Sample Report: Possible Graffiti on Historic Surface. Покажите Specialist Assessment Required и отсутствие записи на удаление граффити. Request Specialist Review фиксирует только локальный запрос.
6. **1:20–1:30:** Generate Draft Appeal. Покажите соответствие выбранному месту, редактирование, Download Draft и отсутствие реальной отправки.

Для проверки публикаций: Demo Review Panel → Moderator Demo → Stories → Fictional Demo Story → Publish as Personal Memory. Даже после публикации воспоминание не получает статус Expert Reviewed. Для направления спорного материала есть Refer for Expert Review и отдельный режим Heritage Specialist Demo, который также не выдаёт настоящего экспертного заключения.

## Файлы

- `index.html`, `styles.css`: адаптивная оболочка, карта и модальные окна.
- `data.js`: неизменяемые сведения о местах, исторические материалы, события и источники.
- `state.js`: создание записей, валидация и правила переходов.
- `app.js`: отображение, карта, формы, взаимодействие и хранение.
- `assets/`: фотографии, атрибуция, исходная иллюстрация, контур Кыргызстана и локальная Leaflet.
- `tests/workflows.test.cjs`, `tests/browser.cjs`: проверки правил и браузерных сценариев.

Исходный прототип найден в `MURAS_Interactive_Demo.html` в папке «Загрузки» и изучен. Оригинал не изменён; его base64-иллюстрация вынесена в `assets/burana-illustration.png`, SVG сохранена в `assets/original-map.svg`. Рабочая папка изначально не содержала исходников; приложение разделено на файлы с сохранением цветовой идентичности и исходных сценариев.

## Проверки

Правила проверяются без установки зависимостей:

```sh
node tests/workflows.test.cjs
```

Браузерный сценарий требует отдельно доступных Playwright и Chromium (Node 20+); они не являются зависимостями приложения. При запущенном статическом сервере:

```sh
node tests/browser.cjs
```

При необходимости задайте `NODE_PATH` к установленному Playwright, `CHROMIUM_PATH` к Chromium, `MURAS_URL` к другому локальному адресу.

Проверены в Chromium: поиск, категории, блокировка записи, весь путь согласования и запись, сохранение после обновления, запрет волонтёрского удаления граффити, редактирование/скачивание обращения, история с фотографией и модерацией, отправка сообщения и предложения, события, offline-атлас, сброс, некорректный localStorage, пошаговый гид. Проверяется отсутствие необработанных JS-ошибок, загрузка изображений и отсутствие горизонтального переполнения на 390 px. Дополнительно проверены автоматический переход в атлас при заблокированных тайлах, копирование обращения, сохранение навигации гида в панели проверки и ширины 768, 1366, 1920 px. Скриншоты проверены визуально. Firefox/Safari и фактическая выдача звука системными голосами не проверялись.

## Ограничения

Все роли и согласования — локальная симуляция. Реальные сообщения организациям, разрешения и экспертные заключения не создаются. Текст и история хранятся только в данном браузере, не синхронизируются. Фото и аудио не отправляются; их предпросмотр действует до обновления страницы, сохраняется только имя файла. Если localStorage переполнен или заблокирован, приложение сообщает, что изменения остаются только в текущей сессии. Автоматическая озвучка зависит от Web Speech API и установленных голосов; она отделена от оригинального пользовательского аудио. Буфер обмена зависит от разрешений браузера; при отказе текст выделяется для ручного копирования. Для реальной эксплуатации необходимы серверная модерация, проверка прав и организация согласований.
